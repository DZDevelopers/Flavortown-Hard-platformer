# Flavortown-Hard-platformer
Hello, my friend.
This is a 2D platformer game I made in Unity. It took me about 13 hours to complete. The main idea behind this game was to make it extremely simple while also being extremely hard. Even though it’s a short game, it’s still hard to beat. And let me assure you, the last part is beatable if you can’t beat it, that’s just a skill issue (Git Gud).
